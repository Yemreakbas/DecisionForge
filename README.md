# DecisionForge
TR: Oyun yapay zekâları için deneysel karar verme mimarisi. JEV, geleneksel AI ve hibrit yaklaşımları karşılaştırır.  
EN: Experimental decision-making architecture for game AI. Compares JEV, traditional AI, and hybrid approaches.

 
## 🇹🇷 Türkçe                                                                                                 

### 📌 Proje Hakkında

**DecisionForge**, oyun yapay zekâlarında karar verme süreçlerini
araştırmak ve farklı yapay zekâ yaklaşımlarını karşılaştırmak amacıyla
geliştirilen deneysel bir projedir.

Projenin temel amacı, **JEV'in oyun AI sistemlerinde bir karar verme
katmanı olarak kullanılabilirliğini** incelemektir.

DecisionForge içerisinde aynı oyun durumu üzerinde farklı karar
yaklaşımları karşılaştırılacaktır:

- Geleneksel kural tabanlı AI
- JEV tabanlı karar verme
- Hibrit AI yaklaşımı

-----------

# 🇬🇧 English

### 📌 About

**DecisionForge** is an experimental project designed to explore
decision-making in game AI and compare different AI approaches.

The main goal of the project is to investigate whether **JEV can be
used as a decision-making layer within game AI systems**.

DecisionForge compares multiple approaches using the same game states:

- Traditional rule-based AI
- JEV-based decision making
- Hybrid AI
